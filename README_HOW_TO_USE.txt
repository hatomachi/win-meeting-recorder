========================================================================
  🎙️ WinMeetingRecorder - 利用ガイド (Windows専用)
========================================================================

■ 概要
Windows専用・ダイアログレス会議記録＆画面差分キャプチャツールです。
相手の声（スピーカー Loopback）と自分の声（マイク）を音割れなく自動合成録音し、
Windows標準機能（MediaFoundation）で24kHzモノラル高圧縮MP3（容量96%削減）へ自動変換。
画面変化を検知してJPEGスクショを保存し、OpenAI Whisper互換APIによる自動文字起こしを行い、
発話テキストとスライド画像が時系列で同期したタイムラインREADME付きで社内GitLabへ自動プッシュします。

■ 使い方
1. 起動:
   - `WinMeetingRecorder.exe` をダブルクリックするだけです。
   - 既定のブラウザ（Edge/Chrome等）で自動的に操作画面 (http://localhost:5000) が開きます。
   - 会社PCに .NET SDK や追加ランタイム、ffmpeg等の外部ツールを入れる必要は一切ありません。

2. 会議の記録:
   - 「社内GitLab連携設定」および「OpenAI Whisper 文字起こし設定」を入力して保存（初回のみ）。
   - 「会議の記録を開始する」ボタンをクリックします。
   - 会議中、重要なスライドを手動で即座に残したい場合は「今すぐスクショを1枚撮影」を押します。

3. 記録の終了:
   - 「記録を停止する」ボタンをクリックします。
   - 音声が自動で超軽量MP3に圧縮され、Whisper APIにより自動文字起こしが行われます。
   - GitLabへ自動プッシュされ、成功するとローカル一時スプールが完全自動削除されます。

4. アプリの終了:
   - 画面右上の「✕ 終了」ボタンをクリックするか、黒いウィンドウで Ctrl + C を押します。

■ コマンドライン引数 (上級者・自動化向け)
   --no-browser, -nb             : 起動時にブラウザを自動で開かない
   --list-devices, -l            : オーディオデバイス一覧を表示
   --list-screens, -ls           : ディスプレイ一覧を表示
   --test-audio, -t [秒数] [パス] : 音声合成テスト録音
   --test-mp3 [WAV] [MP3]        : 音声MP3軽量化 (24kHz Mono 64kbps) テスト
   --test-screen, -ts [秒数]     : 画面変化検知テスト
   --test-gitlab [URL] [Proj] [PAT] : GitLab REST API 接続テスト
   --test-whisper [URL] [音声]   : Whisper API 文字起こしテスト
   --pending-spool               : 未送信ローカルスプール一覧表示
   --help, -h                    : ヘルプ表示
