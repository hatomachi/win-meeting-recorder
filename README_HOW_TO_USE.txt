========================================================================
  🎙️ WinMeetingRecorder - 利用ガイド (Windows専用)
========================================================================

■ 概要
Windows専用・Box API 自動連携 軽量会議記録クライアントです。
相手の声（スピーカー Loopback）と自分の声（マイク）を音割れなく自動合成録音し、
Windows標準機能で 24kHz モノラル高圧縮 MP3（容量96%削減）へ自動変換。
画面変化を検知してJPEGスクショを取得し、会議終了後に指定されたテーマのBoxフォルダへ
音声・スクショ・meta.json を全自動で一括アップロードします。
後続の文字起こしやAI要約は、Boxを監視する後段の集約サーバーが自動で行います。

■ 使い方
1. 起動:
   - `WinMeetingRecorder.exe` をダブルクリックするだけです。
   - 同梱の `config.default.json`（または `config.json`）から社内共通フォルダや企業独自ドメイン（SSO用）が自動ロードされます。
   - 黒いDOS窓は出ず、画面右下のタスクトレイに常駐し、既定ブラウザで操作画面 (http://localhost:5000) が自動オープンします。
   - 会社PCに .NET SDK や追加ランタイム、ffmpeg等の外部ツールを入れる必要は一切ありません。

2. Box 認証（初回のみ）:
   - Web UI または設定欄の「🌐 Boxにログイン」ボタンをクリックします。
   - ブラウザでBoxのログイン・認可画面（企業SSOにも対応）が開くので「許可」を押すだけで連携完了です。
   - トークンは自動でリフレッシュされるため、日々の再ログインは原則不要です。

3. 画面キャプチャ設定のチューニング（任意）:
   - Web UI の「📸 画面キャプチャ＆差分検知設定」または `config.default.json` から設定可能です。
   - チェック周期（デフォルト5秒）、定期強制保存（デフォルト0秒・不要）、差分検知（pHash 8x8 DCT / ハミング距離>5）により、スライド変化時のみ的確にスクショが撮影されます。

4. 会議テーマの選択:
   - 会議開始前に、Web UI またはタスクトレイ右クリックメニューの「📋 テーマ切替」から、
     参加する会議（保存先のBoxフォルダ）を選択します。
   - テーマ一覧は Box 上の共通台帳（themes.json）から自動ロードされます。

5. 会議の記録（Web UI または タスクトレイ）:
   - 【タスクトレイ操作】:
     - トレイアイコンを右クリックして「🔴 記録開始」を押すだけで記録が始まります。
     - 録音中は、トレイアイコンに赤い●RECマークと【リアルタイム音声波形（緑のバー）】が表示されます。
     - 会議中に相手や自分の声が入るとバーがピョコピョコ跳ねるため、会議アプリの裏に隠れていても「チラ見」するだけで確実に録音されている安心感を得られます。
     - トレイメニューから「📸 スクリーンショット撮影」も可能です。
   - 【Web UI操作】:
     - ブラウザ上の「記録開始」ボタンをクリックします。
     - トレイ操作と完全に連動しています。

6. 記録の終了と全自動アップロード:
   - トレイアイコンを右クリックして「⏹️ 記録停止」をクリックするか、Web UIの停止ボタンを押します。
   - 音声が自動で超軽量MP3に圧縮され、Box上にセッションフォルダが自動作成されます。
   - 以下の順序で全ファイルがBoxへ一括アップロードされます：
     1. meeting_audio.mp3 (50MB超は大容量 Chunked Upload Session を利用)
     2. screen_YYYYMMDD_HHMMSS.jpg (差分スクショ全件)
     3. meta.json (★後段サーバーの検知トリガーとして一番最後にアップロード)
   - 送信後、Box APIで見に行って全ファイルの実在・サイズ正常を厳格に確認した上で、
     ローカル一時スプールが完全自動削除されPC容量を圧迫しません。

7. アプリの終了:
   - トレイアイコンを右クリックして「❌ 終了」を選択するか、Web UI右上の「✕ 終了」ボタンをクリックします。

■ コマンドライン引数 (上級者・自動化向け)
   --no-browser, -nb             : 起動時にブラウザを自動で開かない
   --list-devices, -l            : オーディオデバイス一覧を表示
   --list-screens, -ls           : ディスプレイ一覧を表示
   --test-audio, -t [秒数] [パス] : 音声合成テスト録音
   --test-mp3 [WAV] [MP3]        : 音声MP3軽量化 (24kHz Mono 64kbps) テスト
   --test-screen, -ts [秒数]     : 画面変化検知テスト
   --pending-spool               : 未送信ローカルスプール一覧表示
   --help, -h                    : ヘルプ表示
